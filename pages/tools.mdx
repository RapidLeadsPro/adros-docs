# Tool Catalog

Adros exposes its **MCP tools** via Streamable HTTP at `https://api.adros.ai/mcp`. Every tool accepts a `user_token` parameter (auto-injected from the MCP context if present).

This page is grouped by category. Click any category to see all tools and their purposes.

> Looking for how to connect? See the [Quickstart](/quickstart). Looking for the technical deep dive? See the [Technical Overview](/integrations/overview).

## Creative Pipeline (angles and ideas)

The generation layer. Anchored to the pattern DB, your brand context and the Angle Matrix. Ideas and images are billed in credits; a refused call costs nothing and tells your assistant what to do next. Creatives are built only from an idea the owner picked, and the ideas come from a picked angle.

| Tool | Purpose | Credits |
|---|---|---|
| `get_creative_ideation_context` | Free planning, quotes and saved reads. `operation`: `plan` (checklist), `quote` (the credit cap of a paid call; pass the `mode` you plan to run), `list`, `read` (saved idea boards) and `angles_read` (list the brand's angle grids, or one grid by `grid_id`). Also shows your saved audiences (`persona_choice_needed` tells your assistant to ask which). Arguments include `client_name`, `mode`, `product_name` (the offer), `persona_id`, `grid_id`, `task_id`. | 0 |
| `ideate_creative_concepts` | The paid creative engine. `mode="angles"` fills the 40-angle grid for one offer and persona (`refresh=true` re-fills only untested and weak cells). `mode="pick_angles"` saves the owner's `angle_ids` (comma-separated, free). `mode="new"` with `angle_ids` makes three ideas per picked angle, each in a different visual family (up to five angles per call). `more`, `refine` and `combine` extend a board. `mode="select"` saves the owner's picked ideas (`idea_ids`). `render` renders picked ideas (`aspect` `1:1` or `9:16`). `mode="expand"` makes new executions of one confirmed winning angle. `mode="classify_live"` places live ads (`live_ads`) on the grid. Offer: `product_name`. Audience: `persona_id` (`none` for business context only). A paid mode runs only with `subscriber_ideation_confirmation` equal to the free quote. | angles about 4; refresh about 2; picks 0; other modes: the quote's cap, metered; `classify_live` about 2 per 25 ads |
| `build_creative_prompt` | Builds the image prompt for an idea the owner picked, from the idea's saved brief plus brand and business context (Google Performance Max and Display clean assets are the exception). Pass the returned `selected_brief` unchanged. Each approved headline, subheadline and call to action is lettered once on the image. | see your plan's price list |
| `generate_creative` | Renders an ad image from the prompt built for a picked idea (Google Performance Max and Display clean assets are the exception). Needs `subscriber_generation_confirmation` after the owner OKs the credits. Finished images are saved to the Creatives library. Calls are limited to 20 per hour, and an identical call within 60 seconds returns the same image. | catalog credits per saved image, confirmed first |
| `edit_creative` | Fixes an Adros image you already have. Names the image, describes the change in up to 600 characters, needs `subscriber_edit_confirmation`. Images saved from outside Adros cannot be edited this way. | 2 |
| `validate_creative` | Post-generation QA pass: does it match the brief, brand, compliance? | see your plan's price list |
| `verify_visual_reference` | Verify and save a visual reference (a real product, place, logo or uniform) before it is used in an ad | see your plan's price list |
| `analyze_creative_style` | Analyze the style of an external creative (for pattern extraction / inspiration) | see your plan's price list |
| `save_external_creative` | Saves an image you made outside Adros to your Creatives library. It is labelled as external, is not treated as an Adros idea and cannot be edited with `edit_creative`. Arguments: `image_url` (durable HTTP(S) URL), `client_name`, `prompt_used`, `platform`, `aspect_ratio`. | 0 |

Ideas that need the owner's own photo or footage, such as a real founder, practitioner or customer, are shown but never generated.

### Credit cost at a glance

Saving work is free: `create_client_product`, `update_client_product`, `save_external_creative`, `schedule_optimization_review` and `submit_creative_pack_for_review` cost 0 credits. Reads (`get_adros_cycle_status`, `get_adros_skill`, `get_creative_ideation_context`, `check_structure_fit`) cost 0. Picking angles costs 0. A refused call never charges. Every paid call is quoted first and runs only after the owner's OK.

## Auth, rate limits, idempotency

- **Auth:** every tool resolves a user from `X-User-Token` header (MCP) or `user_token` parameter
- **Credit gating:** `CreditGateMCPApp` middleware hard-blocks tool calls when the user's `credits_used >= monthly_credits`
- **Rate limiting:** `generate_creative` capped at **20/hour/user**
- **Idempotency:** `generate_creative` has a **60-second cache** on `hash(prompt[:200] + user_id + aspect_ratio)` to prevent duplicate images from retry storms
- **Logging:** every tool call is logged via `AutoLogMCPApp` middleware for billing + audit
- **Short tool list:** some connections show a short list instead of every tool. Use `list_adros_core_tools` to see what is available, `get_adros_core_tool_schema` for one tool's inputs, `call_adros_core_tool` to run it and `read_adros_core_tool` for reads that change nothing.

## What's NOT a tool

Some Adros functionality is NOT exposed via MCP — it runs automatically:

- **Daily monitor** (6 health checks at 8am SGT) — runs server-side, emits webhook + email
- **Token refresh** (Meta + Google OAuth) — runs hourly in the background
- **Email sequences** (win-back, credit re-engagement) — hourly loops
- **Creative idempotency cache eviction** — 60s automatic

These are listed in the [Technical Overview](/integrations/overview) background loops section.
